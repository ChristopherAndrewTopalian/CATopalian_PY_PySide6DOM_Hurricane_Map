# CATopalian PY PySide6DOM Hurricane Map
This Python PySide6 PySide6DOM application tracks Hurricanes worldwide!
We can click on any Hurricane and it will open the Google map location precisely!

---

REQUIREMENTS:
* Python  
* PySide6  
* PySide6DOM

---

## pip install pyside6dom PySide6
